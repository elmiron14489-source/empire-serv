# Empire Conquest — сервер

Реалтайм-версия игры: Node.js + Express + Socket.io. Все ходы рассылаются
игрокам мгновенно (WebSocket), без задержек в пару секунд.

## Локальная проверка (по желанию)

```
npm install
npm start
```

Откройте http://localhost:3000 в двух вкладках браузера — можно играть.

## Бесплатный деплой на Render.com (самый простой путь)

1. Зайдите на https://render.com и зарегистрируйтесь (можно через GitHub,
   банковская карта не нужна для бесплатного тарифа).
2. Загрузите эту папку в свой репозиторий на GitHub:
   - Создайте новый пустой репозиторий на github.com (например `empire-conquest`).
   - Загрузите в него файлы `package.json`, `server.js`, `README.md` и папку `public/`
     (через веб-интерфейс GitHub — "Add file → Upload files" — если не пользуетесь git).
3. В Render: **New → Web Service** → подключите этот репозиторий.
4. Настройки сборки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. Нажмите **Create Web Service**. Через 1–2 минуты Render выдаст ссылку вида
   `https://empire-conquest-xxxx.onrender.com` — это и есть ваш сайт.
6. Скиньте эту ссылку друзьям. Один из вас создаёт комнату и делится кодом
   или кнопкой «Скопировать ссылку-приглашение» — она уже содержит код комнаты.

**Важный нюанс бесплатного тарифа Render:** если сайтом никто не пользуется
15 минут, сервер "засыпает" и первый заход после паузы грузится ~30–50 секунд,
пока он просыпается. Для игр раз в несколько дней это не проблема. Если это
мешает — на Render есть платный тариф без засыпания (от $7/мес), либо можно
взять Railway.app или Fly.io — процесс деплоя очень похожий.

## Свой домен (по желанию, позже)

1. Купите домен у любого регистратора (Namecheap, Reg.ru, Cloudflare Registrar и т.п.) — от ~$8–12/год.
2. В Render: откройте ваш Web Service → **Settings → Custom Domain** → добавьте
   домен (например `empire.вашдомен.ру`).
3. Render покажет DNS-запись (CNAME), которую нужно добавить в панели
   управления доменом у регистратора. После этого сайт откроется по вашему
   домену вместо `onrender.com`-адреса (обычно 10–60 минут на распространение DNS).

## Что можно докрутить дальше

- Переподключение при разрыве связи (сейчас playerId хранится в localStorage
  браузера, так что при обновлении страницы игрок автоматически "узнаётся" —
  просто нужно снова открыть ту же комнату).
- Сохранение партий между перезапусками сервера (сейчас состояние живёт в
  памяти процесса — если Render перезапустит сервис, активные игры обнулятся).
  Для этого можно подключить бесплатную базу (например Render Postgres или
  Redis) — если понадобится, могу помочь это добавить.
- Аутентификация/аккаунты, если захотите хранить статистику игроков.
